PSPMAN 0.1.0 Alpha
==================

Install
-------
Copy this complete PSPMAN folder to:

  PSP/GAME/PSPMAN

Keep EBOOT.PBP and the assets directory together. Put supported FLAC music in
the Memory Stick MUSIC or PSP/MUSIC directory. PSPMAN supports stereo,
16-bit, 44.1 kHz FLAC for this Alpha.

Controls
--------
D-pad        Navigate
Cross        Select
Circle       Back
Start        Play / pause
Square       Library / Now Playing; Cassette from Now Playing
L / R        Previous / next; hold to seek
Triangle     Track information on Now Playing
Select       About PSPMAN
Home         PSP system exit

Support log and privacy
-----------------------
The diagnostic Alpha writes a bounded local support log at:

  /PSPMAN-HW-DIAG.log

The log stays on the Memory Stick. PSPMAN has no network telemetry and never
uploads it. The log can contain music filenames, paths, tag metadata, build
identity, device/runtime state, and error details. Review it before sharing.
